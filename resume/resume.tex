\begin{itemize}
  \item Built the location service: drivers stream GPS pings over WebSocket into Postgres,
        with an async dual-write to a Redis geo index that serves nearby-driver queries.
        TTL keys and a background sweeper evict stale drivers.
  \item Load-tested it with a Go fleet simulator: 2,000 drivers, 80,000 pings in two
        minutes, zero errors, p99 insert latency 13.7\,ms after sizing the connection pool
        with Little's Law. In a local benchmark, nearby-driver lookups from Redis ran at p99
        3.4\,ms against 103.5\,ms for the same query on PostGIS.
